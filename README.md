## Sobre Mim

Sou **Alexandre Tortoza**, Desenvolvedor Full Stack e UI/UX Designer.

Desde 2020, venho construindo experiências digitais com foco em aplicações bem estruturadas e interfaces elegantes. Atualmente trabalho com **Vue.js**, **React** e **Laravel**, enquanto aprofundo meus conhecimentos em **Inteligência Artificial** e **Machine Learning** na PUC-PR.

Meu objetivo é contribuir para soluções tecnológicas que façam a diferença, sempre buscando aprender, evoluir e gerar impacto positivo.

## Tecnologias Utilizadas

| Tecnologia | Uso |
|:--|:--|
| **Astro** | Framework principal para build estático e otimizado |
| **Tailwind CSS 4** | Estilização utility-first com design system customizado |
| **TypeScript** | Tipagem estática para maior segurança no código |
| **Three.js** | Animação 3D de partículas no hero |
| **AOS** | Animações de scroll suaves |
| **View Transitions API** | Transições fluidas entre páginas |

## Estrutura do Projeto

```
/
├── public/              # Assets estáticos (imagens, ícones, fontes)
├── src/
│   ├── components/      # Componentes Astro reutilizáveis
│   ├── layouts/         # Layout base com SEO e meta tags
│   ├── pages/           # Páginas do site
│   ├── scripts/         # Scripts TypeScript e tipos
│   └── styles/          # Estilos globais e tokens
└── package.json
```

## Comandos

| Comando | Ação |
|:--|:--|
| `pnpm install` | Instala as dependências |
| `pnpm dev` | Inicia o servidor local em `localhost:4321` |
| `pnpm build` | Gera o build de produção em `./dist/` |
